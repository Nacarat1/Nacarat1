### 🚀 Projeto em Destaque

#### [Previsão de Gols: Pipeline Medallion & MLOps](https://github.com/Nacarat1/Copa)
Desenvolvimento de uma arquitetura orientada a dados *end-to-end* para modelagem probabilística de desempenho esportivo.
* **Camada Bronze:** Ingestão automatizada de históricos de partidas via Kaggle API.
* **Camada Silver:** Scripts em Python para tratamento de inconsistências, limpeza e engenharia de atributos (*feature engineering*).
* **Camada Gold & Analytics:** Ajuste de um modelo de Regressão de Poisson integrado a uma simulação estocástica de Monte Carlo executando **100.000 iterações** em produção para mapear cenários de probabilidade.

*Veja todos os detalhes e a documentação metodológica no repositório do projeto.*
